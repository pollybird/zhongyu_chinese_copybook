# 钟毓汉字字帖生成器


## 项目简介


钟毓汉字字帖生成器是一款专业的汉字书写练习工具，支持多种格子类型和生成模式，帮助学生和汉字学习者提高书写水平。


## 功能特点


- **多种格子类型**：支持米字格、田字格、回宫格、作文纸四种格子类型
- **多种生成模式**：支持纯字帖、描红、抄写、描红+抄写四种模式
- **字体选择**：优先使用程序目录font/下的字体，然后使用系统字体
- **丰富的自定义选项**：
  - 字体大小调整
  - 位置偏移设置（X、Y方向）
  - 字帖标题自定义
  - 头部字段自定义（班级、姓名、学号等，支持3个字段）
  - 页码设置（格式和位置）
- **PDF导出**：将生成的字帖导出为PDF文件，方便打印
- **分页预览**：实时预览生成效果，支持上一页/下一页导航
- **工程文件**：支持保存和加载工程文件，方便后续编辑
- **快捷键支持**：提供常用操作的快捷键


## 系统要求


- Windows 10/11 64位系统
- Python 3.7+
- PyQt6
- PyMuPDF


## 安装说明


### 方法一：使用安装程序（推荐）


1. 下载 `钟毓汉字字帖生成器安装程序.exe`
2. 双击运行安装程序，按照提示完成安装
3. 安装完成后，可从开始菜单或桌面快捷方式启动程序


### 方法二：从源码运行


1. 克隆项目到本地
2. 安装依赖：`pip install -r requirements.txt`
3. 运行程序：`python main.py`


## 使用说明


1. **输入内容**：在左侧「输入内容」区域输入要生成字帖的汉字文本
2. **选择字体**：在「字体」下拉菜单中选择合适的字体
3. **调整设置**：在「调整设置」面板中设置字体大小、位置偏移等参数
4. **选择格子类型**：在「线格类型」中选择适合的格子类型
5. **选择模式**：在「生成模式」中选择生成模式
6. **设置标题**：在「标题设置」中输入字帖标题
7. **自定义头部**：在「自定义头部」中设置班级、姓名、学号等信息
8. **页码设置**：在「页码设置」中设置页码格式和位置
9. **预览效果**：在右侧预览区域查看生成效果，使用上一页/下一页按钮导航
10. **保存工程**：点击「保存工程」按钮保存当前配置
11. **导出PDF**：点击「导出PDF」按钮将字帖导出为PDF文件


## 项目结构


- `main.py`：主程序文件，包含主窗口和核心逻辑
- `renderers.py`：格子渲染器模块，负责不同格子类型的绘制
- `utils.py`：工具函数模块，包含页数计算等辅助功能
- `dialogs.py`：对话框模块，包含关于对话框
- `font/`：字体文件目录，包含多种汉字字体
- `app_icon.ico`：应用图标


## 文件关联


程序支持 `.zyzcb` 格式的工程文件，双击该格式文件可直接用本程序打开。


## 常见问题


### 字体加载失败

- 确保 `font/` 目录下存在字体文件
- 如字体加载失败，程序会自动使用系统默认字体


### 导出PDF失败

- 确保目标目录有写入权限
- 检查输入内容是否为空
